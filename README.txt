KAPSA – GitHub Pages

Rozbalte ZIP a nahrajte všechny soubory do kořene repozitáře.
V Settings → Pages zvolte Deploy from a branch → main → / (root) → Save.
Otevřete odkaz z GitHub Pages.
Na iPhonu: Safari → Sdílet → Přidat na plochu.

Data jsou pouze v konkrétním prohlížeči. Před přechodem ze staré adresy stáhněte zálohu JSON a na nové adrese ji obnovte. Data se sama nepřenesou.
Pravidelné splátky jsou plánované výdaje, nikoliv potvrzení bankovní platby.
